# Rocket League Profile Index

An independent reference index of tool profiles for Rocket League.
Each entry collects what public records state, separates verified data from
unverified fields, and keeps the caveats attached.

**Live site:** https://rocket-analytics-tools.github.io/

---

## About

This repository hosts a static reference index. It does not distribute,
host, or mirror any software. Every profile is a written summary and does
not link to a binary.

The index is not affiliated with the game publisher. Modifying the client

## How entries are written

Each profile follows the same rules:

- **Verified vs unverified** — a field is either traced to a public record
  or explicitly marked as untraced. No guessed values are presented as facts.
- **Overlay ≠ safety** — an overlay note describes on-screen presentation,
  not whether a build is safe.
- **No binaries** — no entry links to a file or mirrors one.
